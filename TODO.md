# v0.0.2

- Полноценная поддержка запуска сайта из подпапки (`app.baseURL`). Сейчас в
  `thei.config.json` есть `siteUrl`, но он принимает только origin: адрес с
  путём отклоняется настройками, потому что одного origin для подпапки мало.
  Что нужно: выставлять `app.baseURL` на сборке из `thei.config.json` в
  `update/instance/nuxt.config.tmpl.ts`; один base-aware хелпер поверх
  билдеров путей в `shared/*-url.ts` и поверх всех клиентских
  `$fetch('/api/...')` (~92 места), плюс `/favicon.svg`, `/icons.svg` и
  `window.location.href = '/admin/'` в `sign-in.vue` и `InstallForm.vue`.
  Nitro монтирует роуты по `app.baseURL`, а `TheiLink` резолвит через router
  base, так что они уже готовы — но h3 отдаёт middleware путь без префикса,
  когда route у layer длиннее `/`, и это надо учесть в `0.global.ts`.
  Отдельно: `robots.txt` из подпапки краулеры игнорируют, он обязан лежать в
  корне домена.
  Проанализируй, как Nuxt и Nitro работают с baseURL. Где-то они сами его добавляют при использовании NuxtLink (вроде бы),
  а где-то при составлении ссылки надо вручную его подставлять. Это скользкая тема довольно, возможно свой composable придется написать поверх.
  Четко этот момент обдумай.
